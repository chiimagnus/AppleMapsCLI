### Key Technical Decisions
- **Platform:** macOS 13+ (Ventura) for async/await MapKit support
- **Language:** Swift 6.2.3 with strict concurrency enabled
- **Testing:** Swift Testing framework (NOT XCTest)
- **CLI Framework:** Swift Argument Parser 1.5+
- **VCS:** Jujutsu (jj) for TCR workflow
- **Backend:** Native MapKit/CoreLocation (no API keys required)
- **Output:** JSON-first, snake_case keys, compact when piped, pretty for TTY

### Architecture Boundaries (AGENTS.md §5)
```
Utilities/ → Core/ → Output/ → Commands/ → @main
```
- **Utilities:** Shared helpers, parsing, error types (all Sendable)
- **Core:** MapKit/CoreLocation wrappers, data models, service protocols
- **Output:** JSON/text/table formatters
- **Commands:** ArgumentParser command definitions, CLI routing

### Semantic Exit Codes (AGENTS.md §3)
- `0` — Success
- `1` — User error (invalid args, bad coordinates)
- `2` — Network/API error (MapKit failures, throttling)
- `3` — No results found
